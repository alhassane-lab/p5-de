## p5-de
Maintenez et documentez un système de stockage des données sécurisé et performant

### 1) Clone the repo
git clone https://github.com/alhassane-lab/p5-de.git

### 2) Env config
rename .env.example to .env and complete var envs to ur own

### 3. Run the image
docker compose up -d --build

### 4) verify logs
docker compose logs loader
docker compose logs mongodb
